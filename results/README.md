# Paper-facing result data

| File | Contents |
| --- | --- |
| `main_separation_metrics.csv` | DARS and the three retained separation baselines |
| `category_separation_metrics.csv` | category-wise SDRi/SIR values and bootstrap intervals |
| `ablation_metrics.csv` | patience-10 DARS loss ablations |
| `simulated_rir_metrics.csv` | simulated-RIR comparison on DARS-separated stems |
| `simulated_rir_oracle_metrics.csv` | oracle-input external-estimator control |
| `measured_rir_metrics.csv` | 0716 measured-RIR comparison (balanced-level protocol) |
| `measured_rir_oracle_metrics.csv` | 0716 measured-RIR oracle-input control (balanced-level protocol) |

Only aggregate and plot-source data are included. Generated predictions and
per-example metric files remain excluded from the release candidate.
